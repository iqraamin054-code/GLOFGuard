# REAL environmental training inputs

Generated by `scripts/export_collaboration_training_data.py` from the local
SQLite migration source opened read-only. The exported datasets exclude mock
observations, error logs, outbox payloads, credentials, and SQLite files.

| File | Content | Training use |
|---|---|---|
| `canonical_lakes.csv` | 8,806 reconciled lakes | Feature join key and geography |
| `real_daily_weather.csv` | NASA POWER daily observations | Temporal environmental features |
| `real_hourly_precipitation.csv` | GSMaP rainfall observations | Temporal environmental features |
| `real_forecasts.csv` | GFS forecast features | Forecast feature experiments |
| `real_satellite_observations.csv` | Sentinel-2 observations | Satellite feature experiments |
| `real_time_series_records.csv` | Existing REAL inference records | Evaluation/reference only |

Do not concatenate these files blindly. Join by `lake_id` and timestamps, and
create geographically and temporally separated train/validation/test splits to
avoid leakage. PMD-2013 remains a historical reference, not an automatically
valid model label.
